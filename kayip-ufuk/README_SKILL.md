# Claude Code için Kayıp Ufuk skill paketi

Üç yerel proje becerisi içerir: `/kayip-ufuk-build`, `/kayip-ufuk-assets`, `/kayip-ufuk-qa`.

Skill'ler yalnızca Claude Code veya Agent Skills biçimini okuyabilen bir ajan tarafından yüklenir. `.claude/skills/` dosyalarını Claude Code'un açıldığı proje köküne yerleştir. `CLAUDE.md` ile proje kuralları her oturumda, `SKILL.md` ise gerektiğinde yüklenir. Zip'i sadece Claude sohbetine eklemek otomatik kurulum değildir; arşiv içeriğini açtırmak gerekir.

Bu beceriler oyun motoru veya hazır pixel art dosyası DEĞİLDİR; veri dosyalarını okuyarak sistemi kodlama, görsel varlık üretimi ve kabul testlerini yöneten talimat/süreç paketidir. Bir başka projenin global `~/.claude/skills` klasörüne değil bu proje içine kurulum önerilir.

Tam veri paketi: `Kayip_Ufuk_GDD_v2_0_Kesin_Uretim_Paketi.zip`, veya tek pakette birleştirilmiş sürüm: `Kayip_Ufuk_Opus_Tek_Paket_v2_0.zip`.
