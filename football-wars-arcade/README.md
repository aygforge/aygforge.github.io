# FOOTBALL WARS — ARCADE MAYHEM V2 (and ARCADE REBORN)

Single-file, offline HTML5 arcade football battle game built on the Football Wars V4 deterministic
100 vs 100 *Football Fusion* engine.

**Play:** open `FootballWars_Arcade_Mayhem.html` (current: War Commands) or `FootballWars_Arcade.html` (previous Reborn release, kept unchanged) in any modern desktop or Android browser (no server, no internet).

## Layout

| Path | What |
| --- | --- |
| `FootballWars_Arcade_Mayhem.html` | Current build: War Commands, goal reinforcements, Final Frenzy (~670 KB) |
| `FootballWars_Arcade.html` | Previous Arcade Reborn build (not rebuilt; its sources are in git history) |
| `MAYHEM_TEST_RAPORU.txt`, `TEST_RAPORU.txt` | Test reports (Turkish) |
| `src/v4_*.js` | Unmodified V4 modules (font, director, sprites, audio, and the original engine for regression) |
| `src/engine.js` | V4 engine + opt-in arcade extensions, generated by `tools/build_engine.sh` (`patch_engine.py` + `engine_arcade_ext.js`, then `patch_mayhem.py` + `engine_mayhem_ext.js`) |
| `src/render.js`, `src/v3.js` | V4 renderer + star markers; V3 cosmetic layer without the studio tools |
| `src/data.js` | V4 club database (194 clubs, leagues, metadata) + engine config |
| `src/arcade_data.js` | 200 display names, 6 added clubs, 98 fictional stars |
| `src/arcade_core.js` | Save, Economy, Upgrades, Progression, Stars, Draft, League, Challenges, Endgame, BattleAdapter |
| `src/arcade_audio.js`, `src/arcade_app.js` | Audio, UI, battle loop + War Commands HUD / targeting |
| `tools/` | Build script, engine patcher, tests |

## Build & test

```bash
node tools/build.js            # -> FootballWars_Arcade_Mayhem.html
bash tools/run_tests.sh        # logic + career + browser (Playwright) tests
```

To regenerate the engine from the untouched V4 original: `bash tools/build_engine.sh`.

Independent fan game: adapted club names, original pixel crests/kits and fictional star players; no official
logos, sponsors, licensed kits or real player names/portraits. Club strength source: beyondELO (CC BY 4.0).
Commercial distribution would need a legal review.
