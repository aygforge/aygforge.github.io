# FOOTBALL WARS: ROGUELITE REBORN · ROAD TO GLORY (+ earlier Arcade Mayhem / Arcade Reborn builds)

Single-file, offline HTML5 arcade football battle game built on the Football Wars V4 deterministic
100 vs 100 *Football Fusion* engine.

**Roguelite Reborn (newest):** open `FootballWars_Roguelite_Reborn.html` — a 200-level survivor-first roguelite: a fixed 100-player army, multi-wave missions (140 Survival / 40 Goal Challenge / 20 Total KO), 48 run cards, 5 Star Leaders, Training, Tactical Focus. Report: `TEST_REPORT.txt` (Turkish).

**Road to Glory:** open `FootballWars_Full_Test.html` (current: Road to Glory) — or upload `FootballWars_Full_Test_itch.zip` to itch.io as an HTML5 game. `FootballWars_Arcade_Mayhem.html` and `FootballWars_Arcade.html` are the earlier releases, kept unchanged. in any modern desktop or Android browser (no server, no internet).

## Build & test

```bash
bash tools/run_rogue_tests.sh  # Roguelite: engine + FootballWars_Roguelite_Reborn.html + node and browser tests (--quick for fewer levels)
node tools/build.js            # -> FootballWars_Full_Test.html
python3 tools/make_itch.py     # -> FootballWars_Full_Test_itch.zip
bash tools/run_tests.sh        # engine regression + Road to Glory logic + browser (Playwright) tests
```

To regenerate the engine from the untouched V4 original: `bash tools/build_engine.sh`.

Independent fan game: adapted club names, original pixel crests/kits and fictional star players; no official
logos, sponsors, licensed kits or real player names/portraits. Club strength source: beyondELO (CC BY 4.0).
Commercial distribution would need a legal review.
